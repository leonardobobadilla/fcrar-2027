# FCRAR 2027 website

This folder contains a static website for the 39th Florida Conference on Recent Advances in Robotics.

## Upload to GitHub Pages

1. Create a public GitHub repository named `fcrar-2027`.
2. Upload every file and the `assets` folder from this directory to the root of the repository.
3. In the repository, open **Settings**, then **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.

The default address will be `https://leonardobobadilla.github.io/fcrar-2027/`.
